Troubleshooting Log

Error 1: Login System Not Working

Date Encountered: 24 May 2026

Issue: After adding task management code, the login button stopped responding.

Screenshot of Error:

Login button not responding — console error displayed.

Problematic Code Snippet:


// DOM elements were accessed before the page finished loading
const addTaskBtn = document.getElementById("addTaskBtn");

Cause: JavaScript attempted to access elements before they existed, causing the script to stop executing silently. This prevented the login button event listener from being registered.

Date Resolved: 24 May 2026

Corrected Code Snippet:


window.onload = function() {
    // All code wrapped to ensure DOM is loaded
};

Reflection: This error taught me the importance of ensuring the DOM is fully loaded before accessing elements. Wrapping the script in window.onload prevented silent failures and ensured all event listeners were registered correctly.

Error 2: Edit and Delete Buttons Not Working

Date Encountered: 24 May 2026

Issue: Edit and Delete buttons appeared but did nothing when clicked.

Screenshot of Error:

Edit/Delete buttons inactive — missing function reference.

Problematic Code Snippet:


// Functions were not exposed to global scope
function editTask(index) { ... }

Cause: The functions were defined inside window.onload but not attached to window. Because the HTML uses onclick="editTask(0)", the browser could not find the function.

Date Resolved: 24 May 2026

Corrected Code Snippet:


window.editTask = function(index) { ... }
window.deleteTask = function(index) { ... }

Reflection: This error highlighted the importance of understanding JavaScript scope. Exposing functions to window ensures they can be called from HTML event attributes. It also reinforced the importance of defining global functions before rendering dynamic HTML.
