Ethical Considerations

Developing a study task management system requires careful consideration of ethical principles. Even though this project is a small-scale academic exercise, it still reflects real-world responsibilities that developers must uphold. Ethical design ensures that users are treated fairly, respectfully, and without harm.

One key ethical principle is transparency. Users should understand how the system works, what information is collected, and how their data is used. In this project, no personal data is stored or transmitted. All information remains in the browser session and is cleared when the page is refreshed. This avoids risks associated with data misuse or unauthorised access.

Another important principle is accessibility. The interface was designed with clear contrast, readable text, and simple navigation to ensure that users with different needs can interact with the system effectively. The dark theme also reduces eye strain, especially during extended study sessions.

Privacy Considerations

Privacy is a major concern in modern web applications. Many systems collect, store, and process sensitive user information. This project intentionally avoids storing any personal data. The login system uses a hard-coded username and password purely for demonstration purposes and does not authenticate against a server or database.

All task data is stored temporarily in JavaScript memory and is not saved to local storage, cookies, or external servers. This ensures that no user information persists beyond the current session. If this system were expanded into a real application, additional privacy measures such as encryption, secure authentication, and data minimisation would be required.

The project follows the principle of data minimisation by only collecting the information necessary for the task management functionality. No unnecessary personal details are requested, reducing the risk of privacy breaches.

Reflection

Completing this project highlighted the importance of ethical and privacy-focused thinking in web development. Even simple systems can introduce risks if not designed carefully. By avoiding data storage, limiting user input, and ensuring transparency, this project demonstrates responsible development practices.

If this system were expanded into a full application, I would implement secure authentication, encrypted data storage, and clear privacy policies. This project reinforced the idea that ethical and privacy considerations are not optional—they are essential components of trustworthy software.
